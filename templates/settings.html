Backup & Restore

Keep your system data safe.

No backup created yet this session.

Create Backup opens a folder picker on this computer so you choose exactly where the backup file (.sql) is saved. Nothing is downloaded through the browser.

Restore from Backup File

Load a previously saved .sql backup file from this computer back into the database. This replaces every row currently in the system with what's in the file — it is not merged with existing data. Use this to recover from a backup, or to load a known dataset (e.g. for a defense demo).

Only System Administrators can restore. The restore runs in a single database transaction — if anything in the file fails, nothing is changed.

Automatic Daily Backup

When enabled, Parabellum writes a fresh backup file into a folder you choose on this computer once every 24 hours, whenever an administrator opens Settings. Nothing is ever downloaded through the browser and nothing is sent to the internet.
