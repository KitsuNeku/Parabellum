What do these numbers mean?
  • MAE: average difference between predicted and actual demand, in the material's own unit. Lower is better.
  • RMSE: like MAE but punishes big misses more. Lower is better.
  • MAPE: average error as a percentage of actual demand. Lower is better.
  • R²: how much of the ups and downs the model explains (1.0 = perfect). Higher is better.
  • MLR without weather: the same model with the weather inputs removed, to see if weather helps.
  • Naive: simply guessing that next month equals last month. A useful model should beat it.
